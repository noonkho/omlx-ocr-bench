Sampling

frequency_penalty: 0.8 is the one that matters. On a near-empty page this model repeats the same block to the token cap; 0.8 ends the page cleanly and — measured on a dense page — changes nothing else at all. repetition_penalty at 1.15 also stops the loop but damages layout, and no_repeat_ngram_size (what the official pipeline uses) is accepted by oMLX and then ignored. See the README.

Context window is the model's own, shown next to it above; oMLX takes it from the checkpoint and there is no request field for it.
